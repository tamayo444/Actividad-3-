# Actividad-3-
El objetivo de este trabajo es revisar la credibilidad y exactitud de un análisis por Elementos Finitos aplicado a una barra axial elástica. El sistema está fijo en un extremo y sometido a una carga distribuida a lo largo de toda su extensión junto con una carga puntual en el extremo libre.

Compararemos el comportamiento de la solución aproximada MEF frente al modelo analítico continuo exacto, analizando mallas de 2, 4 y 8 elementos finitos lineales.
